# Avito - отметка брони

Подсвечивает забронированные объявления на Avito оранжевой рамкой и меткой.

## Установка

- **GitHub Releases:** скачайте архив из [последнего релиза](https://github.com/karozero/avito_reserved/releases/latest), распакуйте его, затем в `chrome://extensions` включите режим разработчика и нажмите «Загрузить распакованное расширение», указав распакованную папку.
- **Chrome Web Store:** расширение пока не опубликовано. Ссылка появится после публикации.

## Сборка

Нужен Node.js. В корне проекта выполните:

```sh
npm ci
npm run build
npm test
npm run package
```

Сборка появится в `dist/`, архив для публикации - `avito-reserved-marker.zip`. Подробности: [README на английском](README.en.md).
